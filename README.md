# เลขดี — เว็บแอปวิเคราะห์ "หวยลาว" จากสถิติ

เว็บแอปวิเคราะห์หวยลาว/ฮานอยจากผลย้อนหลังจริง (ตั้งแต่ ม.ค. 2568) ทำงานในไฟล์ `index.html`
**Live:** https://thitiphorn-data.github.io/lekdee-lao-lottery/

รองรับ **5 หวย** (เลือกจากแถบด้านบน): หวยลาว + ฮานอย / ฮานอยพิเศษ / ฮานอย VIP / ฮานอยเฉพาะกิจ

มี 2 หน้า (แท็บด้านบน):
- **วิเคราะห์ช่วงเลข** — แนะนำชุดเลขติดกัน + heatmap + กราฟ + ผลย้อนหลัง
- **สถิติเลข 00–99** — ตารางบอกว่าแต่ละเลข 00–99 ออกเป็น 2 ตัวบน/2 ตัวล่าง ไปกี่ครั้ง คิดเป็นกี่ % (เรียงตามความถี่ได้)

## 🤖 อัปเดตอัตโนมัติทุกคืน
GitHub Actions (`.github/workflows/update.yml`) ตั้งไว้ **22:00 เวลาไทย** (หลังหวยออก)
— GitHub มักเริ่มช้ากว่ากำหนด 2-7 ชม. จริงๆ จะรันราว **ตี 1–5** ไม่กระทบข้อมูล

ทุกคืนระบบจะ:
1. ดึงผลจาก **หลายเว็บ** แล้วเทียบกัน (ดูหัวข้อ "แหล่งข้อมูลและวิธีคิดเลข")
2. **สะสมอย่างเดียว** — งวดที่บันทึกแล้วไม่ถูกลบ (เว็บต้นทางโหลดพลาดก็ไม่ทำให้งวดหาย)
3. ตรวจก่อนบันทึก (`tools/check_data.py`) — งวดหาย / เลขผิดรูปแบบ → **ไม่ commit**
4. push เอง → เว็บมีข้อมูลใหม่อัตโนมัติ (กดรันเองได้ที่แท็บ Actions)
5. ถ้าเว็บให้เลขไม่ตรงกันจนตัดสินไม่ได้ หรือข้อมูลค้าง → **เปิด issue แจ้งเตือน** (GitHub ส่งอีเมลให้)

## 📐 แหล่งข้อมูลและวิธีคิดเลข
ทุกแหล่ง **ฟรี** ไม่ต้องใช้ API key

| ฮานอยปกติ | ทุกวัน 18:30 | **หวยทางการของเวียดนาม (XSMB)** | Minh Ngọc + xoso.com.vn (เว็บผลเวียดนามโดยตรง) |
| ฮานอยเฉพาะกิจ | ทุกวัน 16:30 | ไม่ใช่หวยทางการ ไม่มีแหล่งกลาง | Sanook + สยามรัฐ + บ้านกีฬา |

| ฮานอย VIP | ทุกวัน 19:30 | ไม่ใช่หวยทางการ | Sanook + สยามรัฐ + บ้านกีฬา |

**การตัดเลข (แบบที่คนไทยใช้)**
- **หวยลาว:** ผลออกเป็นเลข 6 ตัว → เลข 4 ตัว = 4 ตัวท้าย · **2 ตัวบน** = 2 ตัวท้ายของเลข 4 ตัว · **2 ตัวล่าง** = 2 ตัวหน้าของเลข 4 ตัว
  เช่น 564693 → 4693 → บน **93** ล่าง **46**
- **ฮานอยทุกประเภท:** กระดานผลแบบ XSMB · **3 ตัวบน / 2 ตัวบน** = ท้าย "รางวัลพิเศษ" (Đặc biệt) · **2 ตัวล่าง** = 2 ตัวท้าย "รางวัลที่ 1" (Giải nhất)
  เช่น ĐB 12554, G1 26733 → 3 ตัวบน **554** บน **54** ล่าง **33**

**ตัดสินยังไงเมื่อเว็บให้เลขไม่ตรงกัน**
- **ฮานอยปกติ:** ถ้า Minh Ngọc กับ xoso.com.vn ตรงกัน = ผลทางการ ชนะเสมอ (ใช้แก้งวดที่เว็บข่าวไทยพิมพ์ผิด)
- **ประเภทอื่น:** ใช้เสียงข้างมาก — วัดจากฮานอยปกติแล้ว เว็บข่าวไทยแต่ละเว็บพิมพ์ผิดราว **2–3%** (Sanook 1.9%, บ้านกีฬา 2.3%, สยามรัฐ 3.2%)
  แต่ผิดไม่ซ้ำงวดกัน 2 ใน 3 เว็บตรงกันจึงเชื่อได้มาก
- **งวดใหม่ต้องมีอย่างน้อย 2 แหล่งตรงกัน** ถึงจะบันทึก · เสมอกัน (1 ต่อ 1) → ไม่เดา ไม่ทับ แจ้งเตือนให้คนตรวจ
- ใน CSV/Excel มีคอลัมน์ **"แหล่งที่ยืนยัน"** บอกว่างวดนั้นตรงกันกี่เว็บ

## ปุ่ม "อัปเดตผลจริง"
**ปกติไม่ต้องกด** — ข้อมูลในตัวอัปเดตเองทุกคืนอยู่แล้ว ปุ่มนี้ไว้ดูงวดของวันนี้ก่อนระบบรอบกลางคืน
หรือเมื่อเปิดหน้าเว็บค้างไว้นานแล้วอยากได้ข้อมูลชุดล่าสุด

กดปุ่ม **⟳ อัปเดตผลจริง** มุมขวาบน แอปจะ:
1. **โหลดข้อมูลที่ตรวจเทียบแล้วชุดล่าสุดจาก GitHub** (ใช้ได้แม้เปิดจากไฟล์ในเครื่อง)
2. **เติมงวดของวันนี้จาก [บ้านกีฬา](https://www.bankeela.info/hanoilottery/)** — ดึงตรง ไม่ต้องผ่าน proxy
   (ฮานอยลงผลราว 19:45 · หวยลาวราว 20:40) งวดพวกนี้มาจากเว็บเดียว จึงใช้ **เติมเฉพาะวันที่ยังไม่มี**
   และขึ้นข้อความว่า "ยังไม่ผ่านการตรวจเทียบ" — รอบกลางคืนจะแทนด้วยข้อมูลที่ตรวจแล้วเอง
3. คำนวณสถิติใหม่ พร้อมป้าย **"ข้อมูลจริง N งวด"**

> หวยลาวออก **จันทร์–ศุกร์** (เสาร์-อาทิตย์และวันหยุดลาวเว้น — ก่อน เม.ย. 2569 ออกแค่ จ/พ/ศ) • ช่วงงวดน้อย % จะแกว่งมาก เป็นเรื่องปกติ

ถ้าขึ้น **"ดึงไม่สำเร็จ"** = เชื่อมต่อทั้ง GitHub และบ้านกีฬาไม่ได้ — ตรวจอินเทอร์เน็ตแล้วกดใหม่
(เดิมปุ่มนี้ดึงจาก Sanook ผ่าน CORS proxy ฟรี แต่ proxy ฟรีทั้ง 6 ตัวใช้ไม่ได้แล้วเมื่อ ต.ค. 2569 — ล่ม / ปิดตัว / ต้องใช้ key จึงเลิกใช้)

ฟิลเตอร์วันที่ใช้รูปแบบ **dd/mm/yyyy** (ปฏิทินเลือกเอง เดือนไทย/พ.ศ.)

## ✅ มีข้อมูลย้อนหลังจริงในตัวแล้ว (ตั้งแต่ ม.ค. 2568)
แอปมาพร้อมผลจริงฝังอยู่ใน `lao_history.js` / `hanoi_history.js` (+ `.json` / `.csv` / `.xlsx`)
จึงวิเคราะห์จากข้อมูลจริงเต็มช่วงได้ทันทีที่เปิด (เปอร์เซ็นต์สมจริง ไม่ใช่ 100% จากไม่กี่งวด)

สคริปต์รัน **ฝั่งเครื่อง/GitHub (ไม่ผ่าน CORS proxy)** จึงไม่โดน rate-limit — ปกติระบบรันเองทุกคืน ไม่ต้องรันเอง

**รันเอง (เช่น ระบบค้างหลายวัน ต้องเติมงวดที่ขาด):**
```bash
pip install openpyxl
python tools/fetch_history.py --full   # หวยลาว: สแกนตั้งแต่ ม.ค. 2568 + เทียบทุกเว็บ
python tools/fetch_hanoi.py --full     # ฮานอย: ย้อนถึง ม.ค. 2568 จากทุกแหล่ง
python tools/check_data.py             # ตรวจว่าไม่มีงวดหาย ก่อน commit
```
ไม่ใส่ `--full` = โหมดรายวัน (ดูย้อนหลังแค่ 1–3 สัปดาห์ เร็วกว่า) · ใช้เวลา `--full` ราว 3–5 นาที
ข้อความ "⚠️ แหล่งข้อมูลไม่ตรงกัน" ในโหมด `--full` = งวดเก่าที่หาแหล่งชี้ขาดไม่ได้ (ระบบคงค่าเดิม/ไม่บันทึกไว้)

## ❓ พรุ่งนี้จะกลับมาดูต้องทำยังไง

**ถ้าใช้บนคอมเครื่องเดิม:** เปิด `index.html` ซ้ำ → ข้อมูลที่เคยกดอัปเดตยังอยู่ (เก็บใน localStorage ของเบราว์เซอร์นั้น) แล้วกด "อัปเดตผลจริง" เพื่อดึงงวดใหม่เพิ่ม

**ถ้าอยากเปิดบนมือถือ / มีลิงก์เข้าได้ทุกที่:** ต้องเอาไฟล์ขึ้นโฮสต์ฟรีก่อน (ไฟล์ในคอมเปิดบนมือถือไม่ได้) วิธีที่ง่ายสุด:

### วิธี A — Netlify Drop (ลากวาง ได้ลิงก์ทันที)
1. เข้า https://app.netlify.com/drop
2. ลากไฟล์ `index.html` (หรือทั้งโฟลเดอร์) ไปวาง
3. ได้ลิงก์ เช่น `https://ชื่อสุ่ม.netlify.app` → เปิดบนมือถือได้เลย เพิ่มลงหน้าจอโฮมได้เหมือนแอป

### วิธี B — tiiny.host (ไม่ต้องสมัครก็ลองได้)
1. เข้า https://tiiny.host
2. อัปโหลด `index.html` → ได้ลิงก์ทันที

> **ข้อควรรู้:** ข้อมูลที่กดอัปเดตเก็บแยกตาม "อุปกรณ์/ลิงก์" (localStorage ต่อ origin)
> เปิดบนมือถือครั้งแรกจะว่าง ต้องกด "อัปเดตผลจริง" บนมือถือเองอีกที แล้วมันจะสะสมของมือถือต่อไป
